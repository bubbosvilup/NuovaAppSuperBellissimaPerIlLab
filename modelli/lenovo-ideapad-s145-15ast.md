# Lenovo IdeaPad S145-15AST

Fonte specifiche: conoscenza generale, da verificare. "AST" = versione con CPU AMD.

## Smontaggio

Fonte guide: ricerca web 2026-10, link verificati salvo dove indicato.

Manuale di servizio Lenovo (HMM, agosto 2019, unico per tutta la serie S145): procedure da 1010 a 1140,
cioè coperchio inferiore, batteria, SSD, RAM, HDD, wifi, ventola/dissipatore, I/O board, batteria CMOS,
scheda madre, upper case con tastiera, LCD, camera, antenne. **Non contiene codici FRU**: i part number
vanno letti sull'etichetta del pezzo.
